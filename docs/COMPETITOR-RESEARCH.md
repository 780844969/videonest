# 万能视频下载器扩展调研：BibiGPT 与 NoteGPT

调研日期：2026-11-11。范围为官方公开页面、价格页，以及 VideoNest 当前代码和历史验收记录。未登录、付费或把用户的视频提交给第三方；下文区分页面可观察事实、厂商描述与产品判断。

## 两条不同的使用路径

| 环节 | BibiGPT | NoteGPT 的 B站摘要页 |
| --- | --- | --- |
| 第一次使用 | 首页提供链接输入和公开演示入口。以节省观看时间解释多平台产品价值。 | 一个 BV 链接输入框、一个生成按钮、四个中文样例。用户不需要先了解整套产品。 |
| 输入 | 官网列出 B站、抖音、快手、播客以及本地音视频、字幕文件。 | 指定页面明确接收 B站视频 URL。站内其他工具的能力不能直接算作该页的输入能力。 |
| 核心交付 | 官网描述为按时间组织的概要、章节、全文转录，可继续追问或生成导图。 | 官网描述为摘要要点可跳回对应时间，配有转录、导图、翻译，可复制或导出笔记。 |
| 读完以后 | 强调把笔记送到 Notion、Obsidian、flomo 等已有目的地。 | 强调保存到自己的工作区，同时提供文本、Markdown 等导出说明。 |
| 升级理由 | 试用按视频分钟计算；更高档面向视觉理解、批量和 API 等需求。 | 工具页宣传基础免费；全站套餐区分基础和高级积分，高级转录按分钟占用额度。 |

来源：[BibiGPT 首页](https://bibigpt.co/en)、[BibiGPT 定价](https://bibigpt.co/en/pricing)、[NoteGPT B站摘要器](https://notegpt.io/cn/bilibili-summarizer)、[NoteGPT 定价](https://notegpt.io/cn/pricing)。

两者的定价不可直接相除：BibiGPT 官网列注册赠送 120 分钟；NoteGPT Pro 页面列每月 1,000 基础积分和 100 高级积分。积分和可总结的视频分钟不是同一单位。NoteGPT 套餐表内部分视频时长限制明确针对 YouTube，不能套用到 B站。两家的实际匿名额度、同一无字幕 BV 的成功率、中文识别准确度、处理耗时和导出权限均未实测。

## 对 VideoNest 的意义

现有用户粘贴链接后，系统已经知道平台、标题、时长和可选格式。因此最值得验证的是：在格式选择旁给出独立的“看内容要点”入口，同一个链接只贴一次；只想下载的人不需要等待 AI。结果最先回答“这段视频讲了什么，哪一段值得看”。例如教程里的“安装失败怎么排查”若附有真实起始时间，比泛泛的“本视频介绍安装流程”更有用。这是建议，不是已确认需求。

| 现有基础 | 容易误判的边界 |
| --- | --- |
| app/main.py 的 /api/analyze 已能解析作品，app/engine.py 能选择视频、合并音视频或导出 MP3 | analyze 返回的是媒体元数据，不是内容分析；音频文件也不是逐字稿。三个平台的下载验收不能代替字幕覆盖率验证。 |
| app/jobs.py 和 app/worker.py 提供独立进程、取消、超时和状态轮询 | 当前最多两个并行任务。长视频转录若直接占用两个位置，会影响下载，这是采用语音识别前应测的成本。 |
| app/static/app.js 已有就绪、下载、保存等交互；本机无数据库、任务文件默认保留 30 分钟 | Markdown 下载符合现状；跨设备历史、长期知识库和付费额度需要额外的存储与身份设计。 |

## 建议确认的优先级

1. 优先验证带时间依据的摘要：有字幕的 B站教程作为起点，结果含概览、要点、出处时间和 Markdown 导出；无字幕时明确说明。不要把标题和简介的改写当作视频摘要。
2. 若无字幕抖音、快手也是首版硬需求，则应先比较本地与云端语音识别。用现有三平台样例外加一条无口播作品，记录文本覆盖、人物或术语错误、等待时间、数据是否离开本机和每分钟成本。
3. 导图、全文问答、笔记库和支付延后。先让用户做一次具体任务：能否通过某个要点找到原片对应片段？若不能，增加展示形式不会解决可信度问题。

## 调研局限与确认点

页面功能描述不是独立效果评测；没有足够证据给两家排准确率或速度名次。下一轮可用同一条允许测试的公开视频对照两家的真实输出，记录登录门槛、时间点偏差、漏项和导出结果。

当前消息中的“@本次需求”未展开。进入方案设计前，应由用户确认扩展目标、首版覆盖的平台及无字幕要求，以及是否允许向第三方模型发送字幕或音频。
