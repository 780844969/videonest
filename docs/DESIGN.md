# 设计与实现决策

用户确认：Python 主栈；轻量后端、第一版无数据库；先完成下载闭环，真实收款后置。优先 B站、抖音、快手，参考截图中的平台导航与多列“更多”菜单。

已在 Edge 无头浏览器实际访问 https://www.videosolo.com/free-video-downloader/ ，保存桌面整页和移动截图。
参考设计：深蓝品牌色、青绿色强调色、浅色工具首屏、集中链接输入区、分步操作说明、功能解释。
本产品：白色导航提升菜单辨识度，深蓝用于主要信息与价值区域，青绿用于主操作；非对称首屏加原创代码绘制的收藏插画，保持下载工具可直接操作。
颜色：深蓝 #182341，主操作 #087c73，浅背景 #f3f8f9。
未复制参考站品牌、图片或评价数据；不展示虚构付费套餐或成功率。
“更多”菜单借鉴用户附图，分平台与工具两列，并附说明；手机收窄成两列。
手机隐藏装饰插画，保留标题、平台选择与输入框。
UI/UX Pro Max 技能已读取；其 scripts/data 在当前安装中是失效的路径占位文件，因此设计检索脚本无法运行。已使用其可访问性、焦点、响应式和减少动态效果规则检查页面。

实现采用独立子进程而非线程执行下载：便于超时终止和关闭 FFmpeg 子进程。
浏览器每 900ms 轮询任务，省去 WebSocket/SSE 依赖。
随机匿名会话 Cookie 隔离任务，无数据库；临时目录仅包含任务产物，不保存用户账户。
链接只接受首批平台和其指定分享域名；短链每次跳转重新校验；后台连接禁止本地/内网地址。
只有可实际下载的 HTTP(S) 格式进入选项列表；格式选择表达式由服务端生成。
